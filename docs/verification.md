# Verification sheet (MICrONS v1926)

Open each link and check that the cells look like the requested type and sit in the requested layer.
Write OK, or what looks wrong, in the last column.

- **Mode** is the `--labels` setting. **Label systems used** is what the mode resolves to for that term: a term may fall back to the only system that defines it (e.g. chandelier exists only in `meso_type`), or require a system in every mode (PV basket, Martinotti).
- **Pool** is the number of matching cells (single-nucleus segments).
- Every row shows cells that no earlier row showed. Classes of at most 30 cells also get a link to all of them, since 3 examples say little about a small class.
- Each link has a `somata` layer whose point descriptions give each cell's labels, depth and proofreading.
- Cells are listed by nucleus ID (stable across releases).
